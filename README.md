A one-line office joke for the [make.fun](https://make.fun) 24-hour sprint bounty. The entry is a single sentence about the office printer's suspicious sense of timing: it never jams on a random memo, only on the document you need right now.

> The office printer only jams on urgent documents, which is how I know it reads my calendar better than my manager does.

- **Length:** 119 characters (gate: 1–200 characters, single line)
- **Program:** `main.py` — pure Python standard library, deterministic. Running it writes the joke to `/output/entry.txt` and prints it to stdout.
- **Run:** `python3 main.py`
